WPS Link Bypass

Paste a WPS share link that asks you to install the app. Get a direct link that opens the file in your browser.

Why does WPS make you install an app?

WPS share links like ap.wps.com/cms/docs/d/... redirect to a promotion page that forces you to install WPS Office. The file itself can be opened directly in any browser.

How this tool works

  • WPS links have two forms: /cms/docs/d/{SID} (install prompt) and /l/{SID} (direct viewer)
  • This tool extracts the SID from your URL and builds the direct viewer link
  • Everything runs in your browser. No data is sent to any server.

Want to save as PDF?

After the file opens in your browser, press Ctrl+P, select "Save as PDF", done. No WPS installed.

Built from frustration with misleading WPS links. 100% client-side. No data collected.
